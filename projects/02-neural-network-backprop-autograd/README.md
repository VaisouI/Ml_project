# Backpropagation и autograd для нейросети

Ручная реализация и анализ обучения нейронной сети без использования фреймворков глубокого обучения в основной логике.

## Что внутри

- Вывод и проверка backpropagation для двухслойного бинарного классификатора.
- Реализация `TwoLayerNet` с ручными `forward`, `backward`, `update`, функцией потерь, предсказанием и точностью.
- Сравнение скорости обучения, инициализации весов, ширины скрытого слоя и активаций ReLU/sigmoid.
- Дополнительные проектные заметки описывают autograd обратного режима на NumPy с `Tensor`, `Linear`, `MLP`, SGD, Momentum и Adam.

## Результаты

| Эксперимент | Ключевой результат |
| --- | --- |
| Подбор скорости обучения | `lr=0.1..1.0` сходились хорошо; `lr=5.0` приводил к случайному уровню точности |
| Инициализация | нулевая инициализация оставалась на `0.5000` точности; случайная достигала `0.9900` |
| Ширина скрытого слоя на moons | полезная нелинейная граница появлялась примерно при `hidden_dim=16..32` |
| ReLU против sigmoid | ReLU давал немного лучшую точность и сохранял более сильные градиенты |
| Autograd-оптимизаторы | Adam показал лучший баланс скорости сходимости и устойчивости в spiral-эксперименте |

## Запуск

Быстрый smoke-тест:

```powershell
python projects\02-neural-network-backprop-autograd\scripts\run_experiments.py --quick
```

Полный воспроизводимый запуск:

```powershell
python projects\02-neural-network-backprop-autograd\scripts\run_experiments.py
```

CSV-таблицы и графики сохраняются в `projects/02-neural-network-backprop-autograd/artifacts/generated/`.

## Структура

- `src/neural_network.py` - двухслойная сеть, forward/backward, loss, prediction и accuracy.
- `src/datasets.py` - генерация синтетических датасетов.
- `src/experiments.py` - воспроизводимые эксперименты и сохранение артефактов.
- `scripts/run_experiments.py` - CLI-точка запуска.
