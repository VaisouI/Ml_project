# Распознавание лиц с SVM и PCA

Воспроизводимый классический ML-пайплайн для классификации лиц: SVM, PCA, перебор по сетке и сохранение артефактов эксперимента.

## Что внутри

- Загрузка ZIP или CSV-датасета с векторами лиц и метками классов.
- Диагностика распределения классов и визуализация средних лиц.
- Обучение базовой Linear SVM и подбор SVM через перебор по сетке.
- Сравнение исходного пространства признаков с PCA-сжатым представлением.
- Сохранение воспроизводимых графиков, таблиц сравнения и обученных моделей.

## Результаты

Сводка репрезентативного запуска:

| Метрика | Значение |
| --- | ---: |
| Строки / признаки | `1326 / 2914` |
| Классы | `12` |
| Базовая Linear SVM, weighted F1 | `0.7673` |
| Лучший SVM в исходном пространстве, weighted F1 | `0.7855` |
| PCA-компоненты для 95% дисперсии | `171` |
| Лучший SVM после PCA, weighted F1 | `0.7627` |

## Данные

Исходный датасет не коммитится. Его нужно положить сюда:

```text
projects/04-face-recognition-svm-pca/data/persons_pics_train.zip
```

или передать свой путь:

```powershell
python projects\04-face-recognition-svm-pca\scripts\run_pipeline.py --data-path path\to\persons_pics_train.zip
```

## Запуск

```powershell
python projects\04-face-recognition-svm-pca\scripts\run_pipeline.py
```

Артефакты сохраняются в `projects/04-face-recognition-svm-pca/artifacts/`.

## Примечание

`artifacts/models/` и подробные отчётные дампы игнорируются, потому что их можно пересоздать. Легкие графики оставлены как визуальное подтверждение запуска.
