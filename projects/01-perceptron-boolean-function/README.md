# Перцептрон для булевой функции

Однонейронный классификатор для булевой функции от четырех переменных. Модель обучается правилом Видроу-Хоффа, а результаты сравниваются для пороговой и сглаженной функций активации.

## Что внутри

- Построение полной таблицы истинности для функции:
  `F(x1,x2,x3,x4) = NOT((x1 AND x2) OR (NOT x3) OR (NOT x4))`.
- Обучение на всех 16 бинарных комбинациях и подсчет полной ошибки Хэмминга после каждой эпохи.
- Поиск минимальных обучающих подмножеств, которые обобщаются на все 16 входов.
- Сохранение истории обучения, проверочных таблиц и графиков.

## Результаты

| Конфигурация | Размер обучения | Эпох до нулевой ошибки | Финальная ошибка |
| --- | ---: | ---: | ---: |
| Пороговая активация, полный набор | 16 | 20 | 0 |
| Сглаженная активация, полный набор | 16 | 16 | 0 |
| Пороговая активация, минимальный набор | 5 | 9 | 0 |
| Сглаженная активация, минимальный набор | 4 | 7 | 0 |

## Запуск

Из корня репозитория:

```powershell
python projects\01-perceptron-boolean-function\src\perceptron_boolean_classifier.py
```

Результаты запуска сохраняются в `projects/01-perceptron-boolean-function/artifacts/generated/`.

По умолчанию используются уже найденные минимальные подмножества, поэтому запуск быстрый. Для полного перебора подмножеств:

```powershell
python projects\01-perceptron-boolean-function\src\perceptron_boolean_classifier.py --exhaustive-minimal-search
```

## Структура

- `src/` - реализация экспериментов с перцептроном.
- `artifacts/tables/` - CSV-таблицы с историей обучения и таблицей истинности.
- `artifacts/plots/` - графики изменения ошибки.

## Что показывает проект

Проект удобно использовать для объяснения того, как базовый нейрон обучается на булевой функции, почему выбор активации влияет на сходимость и как маленькая выборка может проверять обобщающую способность модели.
